2.CONFIGURED ACCESS PORTS (IT Department)
interface range FastEthernet 0/1 - 2
 description IT-Dept-Access
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast        ! Prevents 30-second STP delay for end-user devices
 exit

5.CONFIGURED THE TRUNK LINK TO THE ROUTER
-
interface GigabitEthernet 0/1
 description UPLINK-TO-ROUTER-R1
 switchport mode trunk
 switchport trunk native vlan 99               ! Security best practice: Move native VLAN away from default VLAN 1
 switchport trunk allowed vlan 10,20,30,99     ! Principle of least privilege: Only allow necessary VLANs
 exit

 description UNUSED-PORTS-SHUTDOWN
